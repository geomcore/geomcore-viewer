# geomcore-viewer

Inspect geomcore curves, surfaces, and points in a browser while your Python or Rust code runs. Use the plane view for 2D geometry and the 3D view for spatial geometry. When you add a curve in a surface's parameters, inspect it on the surface and in the `(u, v)` plot.

[Open the live viewer](https://geomcore.github.io/geomcore-viewer/) to try the bundled demo.

- [Get started](quickstart.md) with a Python circle or connect a Rust program to the local server.
- [Inspect geometry](inspection.md) with surface parameters, query results, scalar colours, and lesson steps.
- [Share scenes](sharing.md) as JSON files or embed them in a web page.
- [Find API and protocol details](reference.md) for Python, Rust, and JSON clients.
